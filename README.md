# 🏠 EthioVal: Addis Ababa Real Estate Valuation Predictor

EthioVal is an end-to-end machine learning web application designed to estimate residential property prices across Addis Ababa, Ethiopia.

---

### 🔑 Key Features
* **XGBoost Regression:** Trained model predicting valuations based on subcity location, bedrooms, bathrooms, area ($m^2$), and property type.
* **Streamlit Interface:** Interactive web UI for instantaneous property price estimations in Ethiopian Birr (ETB).

---

### 🛠️ Tech Stack
* Python, XGBoost, Scikit-Learn, Pandas, Joblib, Streamlit
